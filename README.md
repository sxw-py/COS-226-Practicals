# COS 226 — Practical 1: Mutual Exclusion Locks

Implementation of concurrent locking algorithms using two threads in Java.

---

## ▶️ How to Run

**Step 1 — Compile:**
```bash
javac LockOne.java Main.java
```

**Step 2 — Run:**
```bash
java Main
```

Or combine both into one command:
```bash
javac LockOne.java Main.java; java Main
```
